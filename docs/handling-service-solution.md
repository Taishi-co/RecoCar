# 搬运服务撮合方案

## 一、核心定位

### 平台角色

**三种角色**：
1. **需求方**：发布运输需求，需要搬运服务
2. **运力方**：提供无人车运输服务
3. **搬运人员**：提供装车/卸车服务

**平台定位**：
- ✅ 免费撮合平台：连接三方角色
- ✅ 信息展示：展示需求、运力、搬运人员信息
- ✅ 评价系统：服务质量评价
- ❌ 不计算搬运费：费用由双方协商
- ❌ 不记录搬运费：平台不参与交易
- ❌ 不协调时间：时间由需求方和运力方确认

---

## 二、搬运服务流程

### 简化的流程图

```
需求方
  ↓
发布需求
  ├─ 填写货物信息
  └─ 选择是否需要搬运服务
  ↓
等待接单
  ├─ 运力方接单（运输）
  └─ 搬运人员接单（搬运）
  ↓
需求方与运力方确认时间
  ├─ 电话沟通或在线沟通
  └─ 双方确认取货和送货时间
  ↓
装车
  ├─ 搬运人员按时到达
  ├─ 协商搬运费
  ├─ 装车作业
  └─ 需求方支付搬运费（现金或转账）
  ↓
运输
  └─ 运力方运输中
  ↓
卸车
  └─ 搬运人员卸车
  ↓
完成评价
  └─ 需求方评价服务
```

### 关键说明

**1. 费用协商**：
- 平台不计算搬运费
- 需求方和搬运人员通过电话或当面协商
- 费用范围建议：50-150元/次（根据重量）
- 支付方式：现金、微信转账等（平台不参与）

**2. 时间确认**：
- 平台不提供无人车轨迹
- 需求方主动联系运力方，确认取货时间
- 需求方主动联系搬运人员，告知装车时间
- 需求方协调三方时间

**3. 责任划分**：
- 运力方：负责无人车运输
- 搬运人员：负责装车和卸车
- 需求方：负责协调时间和费用协商

## 三、数据库设计（简化版）

### 1. 搬运需求表（简化）

```sql
CREATE TABLE handling_demands (
  id SERIAL PRIMARY KEY,
  demand_id VARCHAR(36) NOT NULL UNIQUE,
  service_type VARCHAR(20) NOT NULL, -- none, full, loading_only, unloading_only
  estimated_weight DECIMAL(10, 2), -- 预估重量（公斤）
  status VARCHAR(20) DEFAULT 'pending', -- pending, assigned, completed
  handler_id VARCHAR(36), -- 接单的搬运人员ID
  assigned_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW(),
  FOREIGN KEY (demand_id) REFERENCES demands(id) ON DELETE CASCADE,
  FOREIGN KEY (handler_id) REFERENCES users(id)
);
```

### 2. 搬运人员信息表

```sql
CREATE TABLE handler_profiles (
  id SERIAL PRIMARY KEY,
  user_id VARCHAR(36) NOT NULL UNIQUE,
  skill_level VARCHAR(20) NOT NULL, -- basic, advanced
  service_area JSONB NOT NULL, -- 服务区域（经纬度矩形）
  phone VARCHAR(20) NOT NULL, -- 手机号
  status VARCHAR(20) DEFAULT 'offline', -- online, busy, offline
  rating DECIMAL(3, 2) DEFAULT 5.0,
  total_orders INTEGER DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW(),
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);
```

## 七、搬运费协商指南

### 平台建议费用范围

**端到端搬运**：
```
≤30kg：40-60元
30-50kg：60-80元
50-70kg：80-100元
70-100kg：100-150元
```

**仅装车/仅卸车**：
```
≤30kg：20-30元
30-50kg：30-40元
50-70kg：40-50元
70-100kg：50-75元
```

### 影响因素

- 重量：越重越贵
- 楼层：无电梯加收10-20元/层
- 距离：搬运距离超过50米加收10元
- 难度：特殊形状或易碎品加收20-30元

### 协商方式

1. 电话沟通
2. 当面协商
3. 装卸完成后支付
4. 支付方式：现金、微信转账、支付宝

## 八、时间协调指南

### 需求方职责

**1. 确认运输时间**：
- 运力方接单后，主动联系运力方
- 确认无人车到达取货点的时间
- 确认无人车到达送货点的时间

**2. 协调搬运人员**：
- 联系搬运人员
- 告知取货时间
- 告知送货时间
- 确保搬运人员按时到达

**3. 应急处理**：
- 如无人车延误，及时通知搬运人员
- 如搬运人员迟到，及时沟通协调

### 沟通流程

```
1. 运力方接单后
   ↓
2. 需求方联系运力方
   ↓
3. 确认无人车到达时间
   ↓
4. 需求方联系搬运人员
   ↓
5. 告知搬运时间
   ↓
6. 搬运人员确认时间
   ↓
7. 按时执行任务
```
