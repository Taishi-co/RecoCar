# 蒙牛奶制品无人车配送平台企业版方案

## 一、方案概述

### 业务背景

**客户定位**：
- 企业：蒙牛奶制品唐山分公司
- 业务：奶制品生产、仓储、配送
- 车辆规模：10-30辆无人车
- 自营网络：20-50个奶站（销售网点）

**配送网络**：

```
┌─────────────────────────────────────────────────────────┐
│                    配送网络                              │
├─────────────────────────────────────────────────────────┤
│                                                            │
│   [仓库/工厂] ──────┐                                     │
│       (取货点)       │                                     │
│                      ├──> [自营奶站1]                      │
│                      │    (内部配送/调货)                   │
│                      ├──> [自营奶站2]                      │
│                      │    (内部配送/调货)                   │
│                      ├──> [自营奶站3]                      │
│                      │    (内部配送/调货)                   │
│                      │                                     │
│                      ├──> [商超A]                          │
│                      │    (对外配送)                       │
│                      ├──> [商超B]                          │
│                      │    (对外配送)                       │
│                      ├──> [代理配送站-丰润区]               │
│                      │    (对外配送)                       │
│                      └──> [代理配送站-路南区]               │
│                           (对外配送)                       │
└─────────────────────────────────────────────────────────┘
```

### 核心需求

1. **一车多装**：一辆车装载多个订单
2. **多装多卸**：多个取货点、多个送货点
3. **路径优化**：自动规划最优配送路线
4. **自有车辆对外服务**：闲置车辆接外部订单
5. **发布外部需求**：自有运力不足时让外部运力方接单
6. **奶站调货**：自营奶站之间互相调货
7. **小程序企业端**：与需求方、运力方界面风格保持一致

## 三、核心业务场景

### 场景1：企业内部批量配送（仓库→自营奶站）

#### 业务背景

**适用场景**：
- 仓库配送到自营奶站
- 批量补货
- 配送频率：每日1-2次

**特点**：
- 同一取货点（仓库）
- 多个送货点（自营奶站）
- 使用自有车辆
- 批量订单（5-20个点）

#### 业务流程

```
企业管理员/调度员发布内部批量配送需求
  ↓
填写统一取货点信息
  ├─ 取货地址：蒙牛奶制品唐山配送中心
  ├─ 联系人：仓库管理员
  └─ 联系电话：138****1234
  ↓
添加多个送货点（奶站）
  ├─ 奶站1：路北万达店，地址XXX，电话XXX
  ├─ 奶站2：路南凤凰店，地址XXX，电话XXX
  ├─ 奶站3：丰润城西店，地址XXX，电话XXX
  └─ ...（可添加5-20个奶站）
  ↓
填写每个奶站的货物信息
  ├─ 奶站1：纯牛奶×20箱，酸奶×30箱
  ├─ 奶站2：纯牛奶×15箱，酸奶×25箱
  └─ 奶站3：纯牛奶×25箱，酸奶×20箱
  ↓
选择配送时间
  ├─ 期望配送时间：今天下午
  └─ 时间段：14:00-17:00
  ↓
系统自动计算
  ├─ 总重量：1800kg
  ├─ 总体积：3.6m³
  └─ 建议车辆：2辆中型车（载重1.5吨）
  ↓
提交需求，进入待调度
  ↓
调度员查看待调度需求
  ↓
选择派车方案
  ├─ 方案1：2辆车，每辆车8-10个点
  ├─ 方案2：3辆车，每辆车5-7个点
  └─ 方案3：系统自动分配
  ↓
确认派车方案
  ↓
系统自动路径优化
  ↓
生成每辆车的配送路线
  ↓
车辆1：仓库→奶站1→奶站2→...→奶站8（8个点）
  ↓
车辆2：仓库→奶站9→奶站10→...→奶站16（8个点）
  ↓
调度员确认路线
  ↓
分配配送员
  ↓
配送员接收任务
  ↓
无人车开始配送
  ↓
逐个奶站配送
  ↓
奶站管理员确认收货（扫码/拍照）
  ↓
配送完成
  ↓
企业内部结算（如需要）
```

#### 路径优化算法

**问题定义**：
- 1个取货点P（仓库）
- n个送货点D1, D2, ..., Dn（奶站，n=5-20）
- m辆车V1, V2, ..., Vm
- 每辆车载重C，容积V
- 找到最优车辆分配和路径

**算法选择**：
- n ≤ 10：遗传算法
- 10 < n ≤ 20：聚类+遗传算法

**优化目标**：
- 总行驶距离最短
- 总配送时间最短
- 车辆负载均衡
- 满足时间窗

**奶站优先级**：
- 紧急补货：优先配送
- 正常补货：按路线优化
- 调货需求：单独处理

### 场景2：企业对外批量配送（仓库→商超/代理配送站）

#### 业务背景

**适用场景**：
- 仓库配送到商超
- 仓库配送到代理配送站
- 配送频率：每日1次

**特点**：
- 同一取货点（仓库）
- 多个送货点（商超/代理配送站）
- 使用自有车辆（优先）或外部运力
- 批量订单（10-30个点）

#### 业务流程

```
企业管理员/调度员发布对外批量配送需求
  ↓
填写统一取货点信息
  ├─ 取货地址：蒙牛奶制品唐山配送中心
  └─ 联系人：仓库管理员
  ↓
添加多个送货点
  ├─ 商超1：华润万家万达店，地址XXX
  ├─ 商超2：永辉超市凤凰店，地址XXX
  ├─ 代理配送站1：丰润区代理站，地址XXX
  └─ ...（可添加10-30个点）
  ↓
填写每个送货点的货物信息
  ├─ 商超1：纯牛奶×50箱，酸奶×40箱
  ├─ 商超2：纯牛奶×45箱，酸奶×35箱
  └─ 代理配送站1：纯牛奶×80箱，酸奶×60箱
  ↓
选择配送时间
  ├─ 期望配送时间：明天上午
  └─ 时间段：8:00-12:00
  ↓
选择运力来源
  ○ 仅自有车辆
  ● 自有车辆优先，不足时外部运力方补充
  ○ 仅外部运力方
  ↓
设置运费范围（如果使用外部运力）
  ├─ 每公里单价：3元
  └─ 总预算：3000元
  ↓
系统自动计算
  ├─ 总重量：3500kg
  ├─ 总体积：7m³
  └─ 建议车辆：3-4辆中型车
  ↓
提交需求
  ↓
系统智能分配
  ├─ 优先分配自有车辆
  ├─ 自有车辆不足时，发布到外部平台
  └─ 外部运力方可接单
  ↓
生成配送方案
  ├─ 自有车辆：2辆，覆盖15个点
  └─ 外部运力方：1辆，覆盖5个点
  ↓
调度员确认方案
  ↓
自有车辆路径优化
  ↓
外部运力方接单（如需要）
  ↓
开始配送
  ↓
逐个送货点配送
  ↓
商超/代理配送站确认收货
  ↓
配送完成
  ↓
结算
  ├─ 自有车辆：企业内部结算
  └─ 外部运力方：企业支付运费
```

#### 商超/代理配送站特点

**商超特点**：
- 配送时间窗严格（如8:00-10:00开店前）
- 货量较大（50-100箱/次）
- 要求准时配送

**代理配送站特点**：
- 配送时间相对灵活
- 货量较大（80-150箱/次）
- 负责再配送到周边

### 场景3：奶站调货

#### 业务背景

**适用场景**：
- 奶站A库存不足
- 奶站B库存充足
- 奶站之间互相调货

**特点**：
- 取货点：奶站B
- 送货点：奶站A
- 临时调货
- 数量相对较小

#### 业务流程

```
奶站A管理员发现库存不足
  ↓
奶站A管理员发起调货申请
  ├─ 调出奶站：奶站B（库存充足）
  ├─ 调入奶站：奶站A
  ├─ 货物：纯牛奶×10箱，酸奶×5箱
  └─ 期望时间：今天下午
  ↓
提交调货申请
  ↓
企业管理员审核
  ├─ 查看奶站B库存
  ├─ 确认调货可行性
  └─ 审核通过
  ↓
系统生成调货单
  ↓
调度员查看调货单
  ↓
安排车辆
  ├─ 选择空闲车辆
  └─ 或使用正在配送的车辆顺路
  ↓
路径优化
  ├─ 如果单独配送：奶站B→奶站A
  └─ 如果顺路：插入到现有路线
  ↓
配送员接收任务
  ↓
奶站B装货
  ↓
配送到奶站A
  ↓
奶站A确认收货
  ↓
库存更新
  ├─ 奶站A库存增加
  └─ 奶站B库存减少
  ↓
调货完成
```

#### 调货类型

**紧急调货**：
- 触发条件：库存<10箱
- 响应时间：2小时内
- 优先级：最高

**常规调货**：
- 触发条件：库存<30箱
- 响应时间：当天
- 优先级：中等

**计划调货**：
- 触发条件：库存<50箱
- 响应时间：次日
- 优先级：最低

### 场景4：自有车辆接外部订单

#### 业务背景

**适用场景**：
- 企业自有车辆闲置
- 车辆利用率不足
- 希望增加收入

**特点**：
- 自有车辆进入公共接单大厅
- 接外部订单
- 收入归企业
- 不影响企业内部优先级

#### 业务流程

```
企业管理员查看车辆状态
  ↓
发现车辆M-001、M-002闲置
  ↓
企业管理员将车辆设置为"对外服务"状态
  ↓
车辆进入公共接单大厅
  ↓
外部需求方发布订单
  ↓
平台智能匹配
  ↓
推荐给车辆M-001
  ↓
配送员（或管理员）查看推荐
  ↓
评估是否影响内部配送
  ├─ 如果不影响内部配送：接单
  └─ 如果影响：拒绝
  ↓
选择接单
  ↓
洽谈运费
  ↓
确认接单
  ↓
系统路径优化
  ↓
开始配送
  ↓
配送完成
  ↓
结算到企业账户
  ↓
企业管理员查看收益
```

#### 车辆状态管理

**车辆状态**：

| 状态 | 说明 | 可接订单 |
|------|------|----------|
| 空闲-内部 | 闲置，仅接企业内部订单 | 内部订单 |
| 空闲-对外 | 闲置，可接外部订单 | 内部+外部订单 |
| 执行-内部 | 正在执行企业内部订单 | 不可接单 |
| 执行-对外 | 正在执行外部订单 | 不可接单 |
| 维修中 | 车辆维修中 | 不可接单 |

**状态切换逻辑**：

```
空闲-内部 → 空闲-对外：企业管理员切换
空闲-对外 → 空闲-内部：企业管理员切换
空闲-对外 → 执行-对外：接单后自动切换
执行-对外 → 空闲-对外：配送完成后自动切换
空闲-内部 → 执行-内部：接内部订单后自动切换
执行-内部 → 空闲-内部：配送完成后自动切换
```

**外部订单优先级**：
- 不影响内部配送：可以接单
- 可能影响内部配送：谨慎接单
- 肯定影响内部配送：拒绝接单

## 五、不影响现有系统设计

### 1. 数据隔离

**企业数据标识**：

```sql
-- 用户表扩展
ALTER TABLE users ADD COLUMN role_type VARCHAR(20);
-- role_type: 'merchant', 'owner', 'enterprise_admin', 'dispatcher', 'station_admin'

-- 企业表
CREATE TABLE enterprises (
  id VARCHAR(36) PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  type VARCHAR(50), -- dairy, logistics
  status VARCHAR(20) DEFAULT 'active',
  created_at TIMESTAMP DEFAULT NOW()
);

-- 奶站表
CREATE TABLE dairy_stations (
  id VARCHAR(36) PRIMARY KEY,
  enterprise_id VARCHAR(36) NOT NULL,
  name VARCHAR(100) NOT NULL,
  address VARCHAR(200),
  manager_id VARCHAR(36),
  phone VARCHAR(20),
  is_owned BOOLEAN DEFAULT true, -- 是否自营
  location JSONB,
  created_at TIMESTAMP DEFAULT NOW(),
  FOREIGN KEY (enterprise_id) REFERENCES enterprises(id)
);

-- 企业订单表
CREATE TABLE enterprise_demands (
  id VARCHAR(36) PRIMARY KEY,
  enterprise_id VARCHAR(36) NOT NULL,
  demand_type VARCHAR(20), -- internal, external
  pickup_address JSONB,
  delivery_addresses JSONB,
  cargo_info JSONB,
  time_window JSONB,
  vehicle_source VARCHAR(20), -- own, external, mixed
  status VARCHAR(20) DEFAULT 'pending',
  created_at TIMESTAMP DEFAULT NOW(),
  FOREIGN KEY (enterprise_id) REFERENCES enterprises(id)
);

-- 调货单表
CREATE TABLE stock_transfer_orders (
  id VARCHAR(36) PRIMARY KEY,
  enterprise_id VARCHAR(36) NOT NULL,
  from_station_id VARCHAR(36) NOT NULL,
  to_station_id VARCHAR(36) NOT NULL,
  transfer_type VARCHAR(20), -- urgent, normal, planned
  cargo_info JSONB,
  expected_time TIMESTAMP,
  status VARCHAR(20) DEFAULT 'pending',
  created_at TIMESTAMP DEFAULT NOW(),
  FOREIGN KEY (enterprise_id) REFERENCES enterprises(id),
  FOREIGN KEY (from_station_id) REFERENCES dairy_stations(id),
  FOREIGN KEY (to_station_id) REFERENCES dairy_stations(id)

```

## 六、路径优化算法设计

### 1. 企业内部批量配送优化

**问题定义**：
- 1个取货点P（仓库）
- n个送货点D1, D2, ..., Dn（奶站，n=5-20）
- m辆车V1, V2, ..., Vm
- 每辆车载重C，容积V
- 找到最优车辆分配和路径

**算法流程**：

```
步骤1：奶站聚类
  - 使用K-means算法，将奶站聚类为m组
  - 每组分配一辆车
  - 确保每组的总重量和总体积不超过车辆限制

步骤2：组内路径优化
  - 对每组使用遗传算法
  - 找到组内最优路径
  - 优化目标：最短距离 + 满足时间窗

步骤3：考虑调货需求
  - 检查是否有紧急调货
  - 优先安排调货车辆
  - 或插入到现有路线

步骤4：负载均衡
  - 检查各组的负载是否均衡
  - 如不均衡，调整分组

步骤5：最终优化
  - 使用模拟退火算法微调
  - 输出最优方案
```

### 2. 对外配送优化（自有+外部）

**问题定义**：
- 1个取货点P（仓库）
- n个送货点D1, D2, ..., Dn（商超/代理配送站，n=10-30）
- 自有车辆数量：m_own
- 外部运力方数量：不限
- 找到最优车辆分配

**算法流程**：

```
步骤1：优先分配自有车辆
  - 计算自有车辆能覆盖的送货点数
  - 优先分配自有车辆

步骤2：剩余点分配
  - 剩余送货点分配给外部运力方
  - 按距离和载重匹配

步骤3：路径优化
  - 自有车辆：内部算法优化
  - 外部运力方：各自优化

步骤4：协调时间
  - 确保所有车辆在时间窗内完成
  - 如有冲突，调整车辆分配
```

### 3. 调货路径优化

**问题定义**：
- 调出奶站A
- 调入奶站B
- 货物数量较小

**算法流程**：

```
步骤1：检查是否有顺路车辆
  - 查找经过A和B的车辆
  - 如有，插入到路线

步骤2：单独配送
  - 如无顺路车辆，安排单独配送
  - 选择最近的空闲车辆

步骤3：优化
  - 简单路径优化
  - 最短距离
```

## 七、结算体系

### 1. 企业内部结算

**适用场景**：
- 企业内部配送
- 奶站调货
- 内部部门之间的结算

**结算方式**：
- 月度结算
- 固定费用（如需要）

**结算流程**：

```
配送完成 → 奶站确认收货 → 生成结算单 → 月末结算 → 完成
```

### 2. 对外配送结算

**适用场景**：
- 自有车辆对外配送
- 外部运力方配送

**自有车辆对外配送**：
- 收益归企业
- 企业得95%，平台5%

**外部运力方配送**：
- 运力方得95%，平台5%
- 企业支付运费

### 3. 外部订单收益

**计算方式**：

```
外部订单收益 = 订单运费 × 95%

示例：
订单运费：50元
企业收益：50 × 95% = 47.5元
平台收益：50 × 5% = 2.5元
```
